
# Rain & Water Effect Experiments

Some experimental rain and water drop effects in different scenarios using WebGL, by Lucas Bebber.

[Article on Codrops](http://tympanus.net/codrops/?p=25417)

[Demo](http://tympanus.net/Development/RainEffect/)

## Unity Port

This repository now includes a **Unity port** of the rain effect! The WebGL effect has been converted to work seamlessly in Unity game scenes.

### Quick Start with Unity

1. Navigate to the `UnityRainEffect` folder
2. Open the project in Unity 2021.3 LTS or higher
3. Open the demo scene: `Assets/Scenes/RainEffectDemo.unity`
4. Assign textures to the Main Camera's `RainEffectSetup` component
5. Press Play to see the rain effect in action

For detailed Unity setup instructions, see [UnityRainEffect/README.md](UnityRainEffect/README.md)

### Unity Features

- ✅ Full conversion of WebGL shaders to Unity HLSL
- ✅ C# scripts replacing JavaScript logic
- ✅ Multiple weather presets (Rain, Storm, Drizzle, Sunny, Fallout)
- ✅ Mouse/touch parallax effect
- ✅ Easy integration with Unity scenes
- ✅ Compatible with Unity 2021.3 LTS and higher
- ✅ Optimized for performance
